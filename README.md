# GameHub PRO

Gaming dashboard, unified library, community, events, Arena, marketplace and Sarvam-powered AI.

> **Development status:** The full project source is being imported and verified. Visual reference screenshots are concepts, not proof of live rewards, provider connections, or game entitlements.

## Security

Do not commit `.env`, `.env.local`, access tokens, session secrets, or production credentials. Rotate any key that was previously shared in chat.

## Stack

Next.js, React, TypeScript, Prisma and Sarvam AI (server-side only).
